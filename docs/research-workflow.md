# Research Workflow

1. Register the source before extracting data.
2. Create one assertion per material claim.
3. Preserve the source wording in `claim_text`.
4. Attach the assertion to the relevant node field.
5. Record both publication date and effective date.
6. Preserve original units; add conversions as separate modelled assertions.
7. Mark conflicts rather than silently reconciling them.
8. A reviewer must approve assertions used in aggregate supply calculations.
